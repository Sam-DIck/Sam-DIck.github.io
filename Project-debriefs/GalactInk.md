# GalactInk
## Overview
Galactink is a tattooing game, where players create and manage a tattoo studio in a vibrant, intergalactic setting.
It started out as our 3rd year university project and was continued into a Dare Finalist entry.

## Key Features
- Animated rich text
- Customizeable colour Palette 


## A Palette That Everyone Can Change
The games colour palette is easily editable by players and designers alike, allowing for a highly personalized visual experience.
These colours can be referenced throughout the game, and a set of custom materials driven by this palette ensures that the visual style remains consistent and adaptable.
